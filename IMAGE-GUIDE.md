# Image Guide

Each case study on the site shows 3 image slots. Drop your edited (Krea-rendered)
images into the `images/` folder using the **exact filenames** below — the site
picks them up automatically, no code changes needed. An empty slot just shows a
placeholder with the expected filename until you add the file.

| Case Study | Filenames |
|---|---|
| Automated Sorting & Handling Line | `sorting-system-1.png`, `sorting-system-2.png`, `sorting-system-3.png` |
| Cold-Tunnel Hibernation Sorter | `hibernation-tunnel-1.png`, `hibernation-tunnel-2.png`, `hibernation-tunnel-3.png` |
| AI-Guided Trolley Loader | `loader-system-1.png`, `loader-system-2.png`, `loader-system-3.png` |
| Single-Actuator Inversion & Separation | `inversion-separation-1.png`, `inversion-separation-2.png`, `inversion-separation-3.png` |
| Non-Contact Channeliser | `channelising-system-1.png`, `channelising-system-2.png`, `channelising-system-3.png` |
| Intelligent Decision-Gate Routing | `decision-gate-1.png`, `decision-gate-2.png`, `decision-gate-3.png` |
| Fail-Safe Distribution | `distribution-system-1.png`, `distribution-system-2.png`, `distribution-system-3.png` |
| Non-Contact Cage & Pooter | `cage-system-1.png`, `cage-system-2.png`, `cage-system-3.png` |
| Low-Cost Arm Rehabilitation Device | `arm-rehab-1.png`, `arm-rehab-2.png`, `arm-rehab-3.png` |

**Notes**
- Slot `-1` renders large (top), slots `-2` and `-3` render side by side below it.
- You don't need all 3 per project — any missing slot just stays a labelled placeholder.
- Need more than 3 images for a project? Say so and I'll extend that project's gallery
  (e.g. add a `-4` slot) — it's a small code change per project, not a rebuild.
- File format: PNG or JPG both work, just match the extension in the filename above,
  or ask me to update the `<img>` `src` for that slot if you export as `.jpg`.
